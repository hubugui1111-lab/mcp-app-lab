## [0.1.0] - 2026-09-03

### Added

- Interactive React workbench for tool calls, App rendering, findings, and protocol traces.
- MCP v2 stdio and Streamable HTTP connectivity with automatic legacy negotiation.
- Distinct-origin double-iframe host using the official MCP Apps bridge.
- Thirteen App resource, schema, CSP, permission, and sandbox checks.
- Deny-by-default navigation, resize clamping, capability downgrade, and origin-bound JSON-RPC transport.
- Redacted recording schema `1.0` and strict deterministic replay.
- Nine adversarial fixture servers plus CLI, unit, UI, integration, E2E, and visual tests.
- English and Chinese documentation, security model, CI, CodeQL, release automation, and launch material.
